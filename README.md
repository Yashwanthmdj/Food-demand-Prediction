🍱 Food Demand Prediction using NARX Neural Network
📌 Project Overview

Food Demand Prediction is an important problem in supply chain and inventory management. Incorrect demand estimation can lead to food wastage, stock shortages, and financial losses.

This project uses a Nonlinear Autoregressive Exogenous Neural Network (NARXNN) to predict future food demand based on historical data and external factors. The system helps improve forecasting accuracy and optimize business operations.

🚀 Features

📊 Predicts food demand using historical data

🤖 Uses NARX Neural Network (Machine Learning model)

📈 Provides accurate predictions with low error rates

📉 Reduces food wastage and operational costs

⚡ Efficient and scalable system
